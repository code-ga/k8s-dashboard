# Fix PV, PVC, StorageClass Routes - Implementation Plan

## Summary of Issues

Comparing PV, PVC, StorageClass routes with properly implemented routes (Pod, Deployment) reveals several critical gaps:

### 1. Database Schema Issues

#### k8sStorageClasses (lines 366-401)
- **Missing `k8sUid`** - Cannot track K8s resource UID for sync
- **Missing `ownerId`** - Cannot track ownership for RBAC
- **Missing `autoCreated`** - Cannot distinguish user-created vs auto-synced
- **Index issue** - Uses `(clusterId, name)` but should have unique index for sync

#### k8sPersistentVolumes (lines 403-440)
- **Missing `k8sUid`** - Cannot track K8s resource UID
- **Missing `ownerId`** - Cannot track ownership
- **Missing `autoCreated`** - Cannot handle externally created PVs
- **Index issue** - Uses non-unique index for sync

#### k8sPersistentVolumeClaims (OK)
- Has all required fields: `k8sUid`, `ownerId`, `autoCreated`

### 2. Route Implementation Issues

#### StorageClass Route
- **No DB insert before agent command** - Unlike pod/deployment which creates DB record first, storageclass.ts just sends command
- **No ownership check on delete** - Missing RBAC
- **No describe endpoint** - Missing feature parity
- **No /:id endpoint** - Uses /:name instead of /:id like other resources
- **No autoCreated flag** - Not set during creation

#### PV Route
- **No k8sUid in schema** - Cannot track real K8s resource
- **No ownerId in schema** - No RBAC
- **No autoCreated in schema** - Cannot handle externally created PVs
- **Delete logic wrong** (lines 170-179) - Checks for k8sUid but schema doesn't have it
- **No describe endpoint**
- **No /:id endpoint** - Uses /:name

#### PVC Route (mostly OK but needs fixes)
- Has ownerId and autoCreated in schema ✅
- Handles k8sUid existence check on delete ✅
- But should also check `autoCreated` field for proper cleanup

## Phase 6: Frontend Considerations

### 6.1 API Response Changes

The frontend will receive new fields in API responses:

**StorageClasses API Response:**
```typescript
// New fields added to response:
{
  id: number;
  clusterId: number;
  name: string;
  provisioner: string;
  reclaimPolicy: string;
  volumeBindingMode: string;
  allowVolumeExpansion: boolean;
  annotations: Record<string, string>;
  labels: Record<string, string>;
  isDefault: boolean;
  // NEW FIELDS:
  k8sUid?: string;        // Track K8s UID
  ownerId?: string;        // For RBAC display
  autoCreated: boolean;    // Distinguish user vs auto-created
  createdAt: Date;
  updatedAt: Date;
}
```

**PVs API Response:**
```typescript
{
  id: number;
  clusterId: number;
  name: string;
  capacity: number;
  phase: string;
  reclaimPolicy: string;
  storageClass: string;
  boundPvc: string;
  accessModes: { data: string[] };
  annotations: Record<string, string>;
  labels: Record<string, string>;
  // NEW FIELDS:
  k8sUid?: string;
  ownerId?: string;
  autoCreated: boolean;
  createdAt: Date;
  updatedAt: Date;
}
```

**PVCs - Already compatible** (has k8sUid, ownerId, autoCreated)
